# Website-Prototyp (Kunden-Seite)

Zwei klickbare Entwürfe: `a.html` (Die Halle) und `b.html` (Farbfelder + Maskottchen Flamo, gewählt).

- `gen.py` baut `a.html`/`b.html` aus `base.css`, `app.js`, `guide.js`/`guide.css` und `menu.json`.
- `menu.json`: Speisekarte (aus `catalog.js` + `menu-source.js`), Bilder in `t/` (aus `dist/client/assets`, verkleinert – nicht eingecheckt, per Skript neu erzeugen).
- `c/`: Freisteller (Essen, Flamo in 7 Outfits, `flamo-bar.webp` und `flamo-talk.webp` als Animation).
- Noch Vorschau: Bestellen sendet nichts; Name/Logo offen.
