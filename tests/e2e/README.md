# اختبارات E2E (Playwright) — Flamo

**التشغيل (على الـ PC):**
1. أول مرة فقط: `npm install` ثم `npx playwright install chromium`
2. `npm run test:e2e` (بدون نافذة) أو `npm run test:e2e:headed` (بتشوف المتصفح)
3. التقرير: `npm run test:e2e:report`

**الأمان:** الاختبار بيشغّل نسخة معزولة من السيرفر على المنفذ **4199** ببيانات فاضية (مجلد مؤقت)، فما بيلمس بيانات المطعم ولا بيطبع ولا بيبعت لسائقين حقيقيين. لازم يكون النظام الحقيقي (4185) مو مأثّر؛ بس ممكن يشتغل بنفس الوقت.

**شو بيفحص:**
- `smoke.spec.mjs`: كل صفحة رئيسية بتنفتح بدون أخطاء JS (كمبيوتر + موبايل).
- `order-flow.spec.mjs`: طلب توصيل كامل (مطبخ ← Live Orders ← توزيع ← سائق ← تسليم)، وطلب Pickup، وإعادة تحميل المطبخ.

**عند الفشل:** لقطة شاشة + فيديو + trace بمجلد `test-results/e2e`.

**المرحلة 2 (لسا):** ضغط واجهة الكاشير نفسها لإنشاء الطلب (الآن الطلب بينحقن عبر API كأنه انبعت من الكاشير).
