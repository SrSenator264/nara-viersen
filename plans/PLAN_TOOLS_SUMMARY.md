## 2. أدوات الصوت والسكرتيرة (من بحث سابق)

- **Pipecat** (BSD-2) و**LiveKit Agents**: إطار لخط الصوت (أذن ← Claude ← فم).
- **OpenClaw** (MIT): محرك وكلاء دايم الشغل. فيه سجل أمان سيء (skills خبيثة، بوابات مفتوحة)، فنستعمل بس skills من عندنا.
- **Nexus Core** (MIT): بديل أخف، بوت تيليجرام مع MCP وموافقة على الأوامر الخطرة.
- أفكار للاستعارة: Vanth-Labs/hannah (موافقات حسب الخطورة، ذاكرة SQLite)، haowenGuo/AILIS (موافقة وسجل تدقيق)، gitphilosopher/MayaVE (مقاطعة بالاسم، لا ترخيص فلا نسخ كود).
- Whisper للتفريغ، وTTS للعربي لسا بالدراسة.

## 3. كيف بتخدم السكرتيرة

السكرتيرة = منسّقة وحدة بتعرف حياتك، وتحتها وكلاء صغار (محاسبة، مطبخ، تسويق).

- **Claude Code + Remote Control** = محرك الوكلاء على كمبيوترك، وتلفونك هو زر الموافقة. هاد نفس فكرة "الموافقات حسب الخطورة": الأوامر الخطرة (حذف، دفع، إرسال) بتستنى زر على الشاشة مش صوت.
- **Skills (anthropics/skills)** = أدوات الوكلاء المتخصصين: docx/pdf لرسائل الموردين، xlsx لتقارير المصاريف.
- **Agent Desktop** = قدرة "تشغيل الكمبيوتر لمهام محددة" (فتح برامج، تعبئة نماذج، نقل بيانات) اللي طلبتها. أخطر قدرة، فنأخرها ونحصرها بمهام معرّفة.
- **OpenHands** = بديل لاحق إذا بدنا لوحة موحّدة لكل الوكلاء. مش ضروري بالبداية.
- **وكلاء التسويق** (PLAN_MARKETING_AGENTS) = أول وكيل متخصص تحت السكرتيرة، وتجربة صغيرة لنمط الشغل كله.
- **من المقال**: ملف قواعد بيتعلّم من تعديلاتك، تقرير أسبوعي، والقرار النهائي إلك. هاي نفس مبادئ السكرتيرة.
- **/brag وFlamo 3D**: للتسويق مش للسكرتيرة، بس بيشاركوها وجه Flamo وتقنية حركة الشفاه إذا قررنا.

## 4. شروط الأمان (للشغل ليل نهار)

- الكمبيوتر شغّال وما يدخل بالسكون، وإنترنت ثابت.
- قائمة أوامر مسموحة مسبقاً (قراءة، اختبارات، commit). الباقي بيستنى موافقتك.
- كل وكيل على مجلد/branch خاص فيه.
- ريبوهات Private، ومفاتيح وكلمات سر خارج الريبو.
- خطر prompt injection من الإيميلات والمواقع.
- بدون صلاحيات بنكية بالبداية.
- راقب استهلاك التوكنز (الحد الأسبوعي).

## 5. أول خطوة عملية (حسب القرار السابق)

أول مهمة للسكرتيرة: **الإيميل والموردين**، وبعدها تقارير مصاريف المطعم.
قبلها نجرّب Remote Control على مشروع صغير (اختبارات أو توثيق) لنشوف التجربة من التلفون.
