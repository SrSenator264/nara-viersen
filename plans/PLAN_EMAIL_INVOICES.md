# خطة: سحب الفواتير من إيميلات Gmail تلقائيًا (Flamo)

## الهدف
سكربت خاص فينا بيجيب الفواتير من كل حسابات Gmail وبيحطها بمحاسبة Flamo، بدون ما نعتمد على أي Connector.

## الطريقة
Gmail API + OAuth (مفتاح دخول لكل حساب)، والسكربت بيشتغل على الـ Synology NAS.

## المراحل
1. **إعداد Google Cloud (مرة وحدة):** مشروع + تفعيل Gmail API + OAuth بصلاحية قراءة فقط (readonly).
2. **ربط الحسابات:** تسجيل دخول لكل حساب Gmail مرة وحدة، وحفظ الـ token بملف آمن على الـ NAS.
3. **السكربت:** يفحص الإيميلات الجديدة، يفلتر الفواتير (مرفق PDF / كلمات مثل Rechnung, Invoice)، ويحفظ المرفقات.
4. **قراءة الـ PDF:** استخراج النص، وإذا الملف صورة ممسوحة نستعمل OCR.
5. **الربط مع المحاسبة:** إرسال (مورّد، تاريخ، مبلغ، رقم فاتورة) لمحاسبة Flamo.
6. **الجدولة:** تشغيل تلقائي على الـ NAS (مثلًا مرة كل ساعة أو كل يوم).

## ملاحظات
- صلاحية قراءة فقط، السكربت ما بيحذف ولا بيرسل شي.
- الـ tokens ما بتنرفع على GitHub أبدًا.
- قبل التنفيذ: نكتب Definition of Done وبتشوفه أول.
- قبل هيك نجرّب Connector الـ Gmail على إيميل فيه PDF لنعرف شو بيقرا.
